## About Me

I'm a mobile and web developer with real production experience — I build, publish, and maintain complete apps on Flutter and native Android, backed by Supabase and Firebase. Several of them are live on Google Play today, including **LinguaLink**, a real-time translation chat app in four languages, and my flagship **Nahw al-Jinan**, a Quran-memorization tracking system built for Dar Al-Quran Kareem wal-Sunnah Association.

I'm extending the same backend and database thinking to the browser: my latest project, **Safwat Al-Tabieen**, is a full Vue 3 + TypeScript PWA with automated parity tests, a strict performance budget, and offline support — live on the web.

## 🚀 Featured Projects

### [LinguaLink – Live Translation](./projects/jisr.md) · ✅ Published on Google Play
A chat and calling app that translates everything in real time — text, voice notes, video subtitles, text in photos, live calls, and group chats — across **Arabic, English, Italian, and Spanish**. Built end to end: Flutter client, Supabase backend, and an AI pipeline (Whisper → Gemini → TTS) kept behind Edge Functions so no API key ships in the app.

`Flutter` `GetX` `Supabase` `Agora RTC` `Whisper` `Gemini` `FFmpeg`

[▶ Google Play](https://play.google.com/store/apps/details?id=com.translate.ai)

### [Safwat Al-Tabieen (صفوة التابعين)](./projects/safwa-tabieen.md) · 🌐 Live web app
A fast, installable Arabic PWA for tracking Quran memorization — student, teacher, and admin roles, individual daily plans, color-coded progress, and rankings. A complete **Vue 3 + TypeScript rebuild** of my Flutter app that cut the first load from ≈ 2.5 MB to ≈ 90 KB of JS, opens offline, and is verified against the original by **93 golden tests**.

`Vue 3` `TypeScript` `Vite` `Vitest` `Supabase` `PWA`

[🌐 Live site](https://huffaz-tabieen.netlify.app/) · [💻 Source](https://github.com/ObaidaAlaff/safwa-tabieen-web)

### [Nahw al-Jinan (نحو الجِنان)](./projects/nahw-al-jinan.md) · ✅ Published on Google Play
A complete Quran-memorization tracking app for **Dar Al-Quran Kareem wal-Sunnah Association** — three roles (admin/teacher/student), full Arabic RTL interface, daily reports, assessments, chat with calls, and a financial module. Backed by a 30+ table Supabase schema with Row Level Security.

`Flutter` `GetX` `Supabase` `PostgreSQL`
